# Анимации XP в профиле Upscale

Статическое демо входа в профиль на основе фрагментов тестового Upscale.

## Запуск

В каталоге репозитория запусти локальный сервер.

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Открой [общий экран](http://127.0.0.1:8080/overview.html). Кнопка «Повторить вход» запускает анимации заново. Переключатель «Вдвое медленнее» помогает рассмотреть движение.

## Что можно посмотреть

- [Общий экран](overview.html) показывает блик на бейдже, раскрытие наград, свечение молний перед прыжками карточек и одновременное заполнение шкал uXP и заданий. Весь проход длится 1,18 с. Числа видны с первого кадра.
- [Анимации бейджа](index.html) показывают появление бейджа и блик по металлу.
- [Отдельные варианты](more.html) показывают прыжки карточек, раскрытие наград и подсветку молнии.

Значения и начисление опыта демонстрационные.
